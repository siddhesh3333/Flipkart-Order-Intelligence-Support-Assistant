# Document ID: POL-001
# Title: Returns Policy

Customers may request a return for an eligible product within the return window displayed on the product or order page.

The applicable return window may differ by product category and seller.

A return request must be submitted through the order support flow before the applicable return window expires.

Products must satisfy the applicable return-condition requirements for the return to be accepted.

Some products may be non-returnable because of product type, hygiene requirements, safety considerations, or seller-specific restrictions.

When a return request is approved, the customer may be required to provide the product for pickup or follow the applicable return instructions.

A return request may be rejected when the product is outside the eligible return period or does not satisfy the applicable return conditions.
