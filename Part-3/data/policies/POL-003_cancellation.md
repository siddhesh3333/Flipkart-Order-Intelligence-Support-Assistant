# Document ID: POL-003
# Title: Order Cancellation Policy

A customer may request cancellation while the order is still eligible for cancellation.

Cancellation availability depends on the current order status and fulfillment stage.

An order that has already entered a non-cancellable fulfillment stage may not be cancellable through the normal cancellation flow.

If cancellation is successful, the customer receives confirmation through the applicable order or support channel.

For prepaid orders, an eligible cancellation may result in a refund according to the refund policy.

If an order cannot be cancelled because it has progressed too far in fulfillment, the customer may need to use the applicable return process after delivery if the product is eligible for return.

Customers should check the current order status before requesting cancellation.
